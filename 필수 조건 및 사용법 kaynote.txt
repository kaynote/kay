* 사용법: PowerShell을 열고 node build.js 입력하면,
people.js가 생성된다. (또는, build.bat 더블클릭으로 people.js가 자동으로 생긴다). 사진이 추가될 때마다 반복 업로드.

* firebase와 연동하여 GitHub Pages (kaynote.github.io/kay)에 좋아요 + 댓글 달기.

* GitHub에서 images 폴더 만드는 방법: Add file - Create new file에서 images/.gitkeep 입력한다.

-----------------------------------------------------------

* 댓글과 답글 알림의 파일별 역할

index.html
 └─ 알림 버튼 UI

style.css
 └─ 알림창 디자인

firebase.js
 └─ Firestore CRUD
 └─ 실시간 리스너
 └─ 알림 저장

main.js
 └─ 댓글
 └─ 답글
 └─ 알림 표시
 └─ 댓글 이동

* 댓글 구조도

295개 카드 (모두 관리자 작성)

┌─ 민수
│   ├─ A 댓글
│   ├─ B 댓글
│   └─ C 답글
│
└─ D가 새 댓글 작성
      ↓
알림 대상
✔ 관리자
✔ A
✔ B
✔ C
✖ 민희 게시글에서만 활동한 사람
✖ 한 번도 댓글을 안 단 사람
